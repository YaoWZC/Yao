# Yao — 临床药学 / 药物经济学研究工作区

本仓库承载一项卫生经济学评价的**可复现交付物**：研究方案、证据提取表、模型代码、结果表与稿件。

它不是文档仓库，而是**流水线**：每个结论都必须能从仓库里的某个文件追出来。

## 目录

| 目录 | 放什么 | 谁维护 |
|---|---|---|
| `protocol/` | PICO、视角、时间跨度、分析计划 | 人 |
| `evidence/` | 检索式、PRISMA 记录、数据提取表与字段定义 | 人 + agent（按规则） |
| `model/` | 参数表、模型代码、校验脚本 | agent（按规则） |
| `outputs/` | 模型跑出来的结果表、图 | agent 自动生成 |
| `manuscript/` | 稿件与表格 | 人 + agent（按规则） |
| `checks/` | 一致性校验脚本 | agent |

## 三条硬规矩

1. **每个数值都要有出处。** 参数表里的 `source` 必须指向 `evidence/extraction.csv` 里的 `literature_id`，或一个明确的公开来源。
2. **不得推断缺失值。** 缺失写 `NA` 并在 `note` 列说明，不做插补、不估算。
3. **不得存放患者级数据。** 本仓库只放聚合参数、文献值与模拟数据；病例、处方明细、TDM 结果一律不入库。

详见 [SOP.md](SOP.md)。
